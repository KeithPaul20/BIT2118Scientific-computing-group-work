# Task 11: Root Finding Using Newton-Raphson and Secant Methods

## 1. Objective

To demonstrate how Newton-Raphson and Secant methods can be used to solve nonlinear equations and find unknown values efficiently. The task compares two powerful root-finding techniques commonly used in scientific computing, engineering and finance.

## 2. Concepts Covered

- Nonlinear equations.
- Root finding.
- Newton-Raphson Method.
- Secant Method.
- Numerical approximation.
- Internal Rate of Return (IRR).
- Convergence analysis.

## 3. Original Problem

A financial application is required to determine the interest rate that makes the Net Present Value (NPV) of a project equal to zero. This interest rate is known as the Internal Rate of Return (IRR).

### Input Data

Cash Flows:

```text
[-10000, 3000, 3500, 4000, 2500]
```

Initial Newton-Raphson Guess:

```text
10%
```

Initial Secant Guesses:

```text
5%
20%
```

### Mathematical Operations

1. Net Present Value Equation

```text
NPV(r) = Σ [CFt / (1+r)^t]
```

2. Newton-Raphson Formula

```text
x(n+1) = x(n) - f(xn)/f'(xn)
```

3. Secant Formula

```text
x(n+1) = x(n) - f(xn)(xn - x(n-1))
          -------------------------
          f(xn) - f(x(n-1))
```

### Output Interpretation

The root obtained represents the interest rate that causes the project's NPV to become zero.

Both Newton-Raphson and Secant methods should converge to nearly the same IRR value.

## 4. Parameter Modification

The initial investment was changed from:

```text
-10000
```

to:

```text
-12000
```

### Observed Changes

- The Internal Rate of Return decreased.
- The root shifted to a lower value.
- More iterations were required before convergence.

### Interpretation

A higher initial investment increases project costs, reducing profitability. As a result, the interest rate that makes NPV equal to zero becomes smaller.

## 5. Related Real-World Application: Investment Return Analysis

An investor wants to determine the annual rate of return generated by an investment project. The project requires an initial investment and generates positive cash flows over several years.

### Input Data

Cash Flows:

```text
[-50000, 12000, 15000, 18000, 20000]
```

Initial Newton-Raphson Guess:

```text
10%
```

Initial Secant Guesses:

```text
5%
20%
```

### Assumptions

- Cash flows occur at the end of each year.
- The projected cash flows are accurate.
- No additional costs are incurred during the investment period.
- The investment remains active for the full duration.

### Operations Performed

- Net Present Value calculation.
- Newton-Raphson root finding.
- Secant Method root finding.
- Verification of NPV at the calculated IRR.

### Output Interpretation

The calculated IRR represents the annual rate of return generated by the investment.

A positive IRR indicates profitability, while a lower IRR suggests reduced financial performance.

The NPV value at the calculated IRR should be very close to zero, confirming the correctness of the solution.
